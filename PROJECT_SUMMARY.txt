1. MAJOR CHANGES
--------------------------------------------------------------------------------
- Stack Modernization: Migrated from static HTML/CSS/JS to React 18, Vite 5,
  TypeScript 5, and Tailwind CSS.
- Single Source of Truth: Centralized all wedding details, timings, venues,
  and media in src/config/weddingConfig.ts.
- Dual Luxury Themes: Added Warm Cream Editorial (Light) and Midnight Champagne
  (Dark) with persistent toggle.
- Autoplay & Audio Unlock: Instant 0ms HTML5 autoplay with first touch/click
  gesture unlock and live equalizer pill (Music ON / OFF).
- Standardized Dates: Engagement (4 Feb 2026), Holy Matrimony (3 Feb 2027),
  Reception (4 Feb 2027). Zero RSVP forms, zero Thanksgiving mentions.
- WhatsApp Integrations: Added guest invitation generator and developer connect.
- Automated Testing: 49 unit tests + 95 CDP browser assertions (100% passing).
- Multi-Cloud Hosting: Production CI/CD on Vercel and GitHub Pages.

4. IMPROVEMENTS SUMMARY
--------------------------------------------------------------------------------
[New Features]
- Real-time wedding countdown grid with Google Calendar sync and .ics downloads.
- Touch-friendly fullscreen photo lightbox with zoom and counter.

[Technical Optimizations]
- Vite bundle splitting (vendor-react, vendor-motion, vendor-media).
